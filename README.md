# homework-19

## Описание

Одностраничное приложение (SPA) для просмотра информации о персонажах, локациях и эпизодах мультсериала **Rick and Morty**.

Проект был переработан с упором на:

- **архитектуру Feature-Sliced Design**
- **использование дизайн-системы Mantine**
- читаемость кода и масштабируемость

---

## Основной функционал

- Авторизация пользователя (имитация)
- Защита приватных маршрутов
- Просмотр списков:
  - персонажей
  - локаций
  - эпизодов
- Просмотр детальной информации
- Бесконечная прокрутка (infinite scroll)
- Lazy loading страниц
- Централизованный layout
- Адаптивный UI

---

## Используемые технологии

- **Vite**
- **React 18**
- **TypeScript**
- **React Router v6**
- **Mantine (UI / AppShell / Layout)**
- **Feature-Sliced Design**
- **IntersectionObserver API**
- **localStorage** (хранение состояния авторизации)

---

### Принципы

- **Pages** — только композиция и навигация
- **Entities** — доменная логика и UI
- **Features** — бизнес-логика (авторизация)
- **Widgets** — layout и крупные блоки интерфейса
- **Shared** — переиспользуемый фундамент

---

## Авторизация

- Реализована через `features/auth`
- Состояние авторизации хранится в `localStorage`
- После входа пользователь получает доступ к приватным маршрутам
- Реализован `PrivateRoute`

---

## UI и стили

- Используется **Mantine** как дизайн-система
- Layout реализован через `AppShell`
- Основной контент центрирован с помощью `Container`
- Минималистичный, аккуратный и адаптивный интерфейс
