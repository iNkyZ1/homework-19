# homework-18

## Описание

Одностраничное приложение (SPA) для просмотра информации о персонажах, локациях и эпизодах мультсериала **Rick and Morty**.

В этом задании реализованы следующие ключевые функции:

- **Авторизация пользователя**
- **Защита приватных маршрутов**
- **Ленивая загрузка страниц**
- **Error Boundary**
- **Бесконечная прокрутка (infinite scroll)**

---

## Используемые технологии

- **Vite**
- **React 18+**
- **TypeScript**
- **React Router v6**
- **Context API**
- **React.lazy / Suspense**
- **Error Boundaries**
- **IntersectionObserver API**

---

## Функциональность

- Главная страница с навигацией
- Страница входа (`/login`) с имитацией авторизации (логин/пароль не проверяются)
- Состояние авторизации сохраняется в `localStorage`
- Приватные маршруты:
  - `/characters`, `/characters/:id`
  - `/locations`, `/locations/:id`
  - `/episodes`, `/episodes/:id`
- Lazy loading всех страниц
- Обработка ошибок через `ErrorBoundary` (внутри контента)
- Бесконечная прокрутка (infinite scroll) при скролле вниз
- Данные загружаются **с публичного API**, не из локальных файлов
